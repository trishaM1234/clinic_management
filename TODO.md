# Fix Plan for Clinic Appointment System

## Issues Found & Fixes

### 1. `app.py` - Oracle IDENTITY Insert Bug
- **Problem**: `add_appointment()` inserts `appointments_seq.NEXTVAL` into `id`, but table uses `GENERATED BY DEFAULT AS IDENTITY` (no sequence exists).
- **Fix**: Remove `id` column from INSERT to let Oracle auto-generate it.

### 2. `app.py` - Date/Time Parameter Handling
- **Problem**: Frontend sends combined datetime string, but backend expects separate `appointment_date` and `appointment_time`.
- **Fix**: Ensure backend binds both fields correctly from JSON payload.

### 3. `static/js/dashboard.js` - Missing `reloadDashboard()`
- **Problem**: Called after creating appointment but never defined.
- **Fix**: Add `reloadDashboard()` that routes to correct loader based on page path.

### 4. `static/js/dashboard.js` - Date/Time Format Bug
- **Problem**: Frontend concatenates `date + " " + time + ":00"` into single `appointment_date` field.
- **Fix**: Send `appointment_date` and `appointment_time` as separate fields in POST body.

### 5. `static/js/dashboard.js` - Empty Dropdowns (Admin & User)
- **Problem**: `<select id="appointment-user">`, `<select id="appointment-staff">` never populated.
- **Fix**: Add `loadUsers()` to fetch `/api/users`, populate dropdowns, and render user list table.

### 6. `static/js/dashboard.js` - Admin User List Not Rendered
- **Problem**: `#user-list` div exists but no code renders users.
- **Fix**: Add `renderUsers()` function and call it in `loadAdminDashboard()`.

### 7. `static/js/dashboard.js` - Logout Button Not Wired
- **Problem**: `#logout-button` exists in HTML but no click listener.
- **Fix**: Add event listener for logout button.

### 8. `static/js/auth.js` - Dead Code
- **Problem**: `createAppointment()` references non-existent HTML elements.
- **Fix**: Remove unused `createAppointment` function and related listener.
